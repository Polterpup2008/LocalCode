Three steps to your first task.

The app and runtime come together. Bring your own compatible GGUF model.

  1. Install or extract

    Run the installer, or extract the full portable ZIP and open bin\LocalCode.exe.

  2. Add a local model

    Choose File → Add GGUF model…, select your model, review its profile and load it.

  3. Choose a workspace

    Open a project or choose Work without a project. Give it a small task and review the result.
